# Machine Learning Lab

Hands-on machine learning notebooks, laboratory exercises, and projects covering the fundamental concepts of supervised and unsupervised learning.

The repository demonstrates the practical application of machine learning algorithms through exercises, data analysis, model development and end-to-end projects. It includes implementations of commonly used ML techniques alongside two larger projects focusing on clustering and classification.

The work emphasizes understanding the complete machine learning workflow, including data preprocessing, feature engineering, model training, evaluation, visualization, and performance comparison.

## Repository Contents

### Machine Learning Fundamentals

A collection of Jupyter notebooks covering topics such as:

- Data preprocessing
- Feature engineering
- Data visualization
- Model evaluation
- Cross-validation
- Hyperparameter tuning
- Performance metrics

### Supervised Learning

Hands-on implementations of supervised learning algorithms including:
- Linear Regression
- Logistic Regression
- Decision Trees
- Random Forests
- Support Vector Machines
- K-Nearest Neighbors
- Ensemble methods

### Unsupervised Learning

Practical exercises covering:
- K-Means Clustering
- Hierarchical Clustering
- Gaussian Mixture Models
- Principal Component Analysis (PCA)
- Cluster evaluation techniques

### Projects

#### Unsupervised Learning Project

An end-to-end clustering project exploring unsupervised learning techniques for discovering patterns within unlabeled datasets.

#### Supervised Learning Project

A classification project developed for the **WiDS Datathon 2025 Kaggle Competition**, involving data preprocessing, feature engineering, model training, and predictive performance evaluation.
